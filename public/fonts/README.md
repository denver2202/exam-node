# Шрифт PT Sans (офлайн)

На экзамене интернета нет — Google Fonts не подтянется.

1. Скачайте PT Sans заранее (или с флешки площадки).
2. Положите файлы сюда, например:
   - `PTSans-Regular.ttf`
   - `PTSans-Bold.ttf`
   - `PTSans-Italic.ttf`
3. Раскомментируйте `@font-face` в `public/css/style.css`.
