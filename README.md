# Конференции.РФ — учебный каркас ДЭ

Node.js + EJS + PostgreSQL (`"type": "module"`) + `.env`.  
Максимально простой монолит: один `server.js`, без ORM и Nest.

> На площадке ДЭ чаще PHP/Python + MySQL. Node не запрещён, но могут не поднять — этот проект для тренировки и если Node разрешён.

## Быстрый старт

1. Установите Node.js ≥ 18 и PostgreSQL.
2. Создайте БД и таблицы:

```sql
CREATE DATABASE conferences;
```

```bash
psql -U postgres -d conferences -f schema.sql
```

3. Скопируйте env и поправьте пароль:

```bash
copy .env.example .env
```

4. Установите зависимости и запустите:

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Что где лежит

| Файл | Зачем |
|------|--------|
| `server.js` | все роуты, сессии, middleware |
| `db.js` | подключение `pg.Pool` |
| `validation.js` | regex по ТЗ |
| `schema.sql` | таблицы + помещения |
| `views/` | EJS-страницы |
| `public/css/style.css` | фирменный стиль, адаптив, анимации |
| `er/` | сюда скрин ER из pgAdmin/DBeaver |

## Страницы

- `/register` — регистрация («Создать пользователя»)
- `/login` — вход + ссылка на регистрацию
- `/applications` — мои заявки + отзыв (только статус «Завершено»)
- `/applications/new` — новая заявка (select помещение / оплата)
- `/admin` — фильтр, карточки, смена статуса

Статусы: **Новая → Мероприятие назначено → Завершено**

## Валидация (ТЗ)

- Логин: латиница и цифры, ≥ 6, уникальный  
- Пароль: ≥ 8  
- ФИО: кириллица и пробелы  
- Телефон: `8(XXX)XXX-XX-XX`  
- Email: обычный формат  
- Все поля обязательные  

Ошибки показываются на форме. Пароли хранятся через `bcrypt`.

## Офлайн (нет интернета)

1. `npm install` сделайте **до** экзамена или с локального кэша/`node_modules` на флешке.
2. Шрифт PT Sans — в `public/fonts/` (см. README там), раскомментируйте `@font-face` в CSS.
3. Google Fonts в `header.ejs` можно удалить — останется локальный шрифт / Arial.
